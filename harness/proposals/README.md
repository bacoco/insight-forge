# Rule proposals

Generated by `python3 scripts/propose_rules.py`. One file per proposed rule
edit, named `<UTC-timestamp>-<rule_id>.yaml`.

The proposer never edits `rules.yaml` directly — same conservative contract
as `propose_claude_md.py` does for `CLAUDE.md` / `AGENTS.md`. The user
reviews each proposal and applies it by hand.

## Proposal format

```yaml
created_at: 2026-05-05T12:15:50+00:00
proposer: deterministic-mutation-search-v1
target_rule: R-HEURISTIC-ALWAYS-NEVER
gap_fixture: french_heuristic
candidate_phrase: il faut
metric_delta:
  fixtures_fixed: [french_heuristic]
  regressions: []
  score: 1
before:
  id: R-HEURISTIC-ALWAYS-NEVER
  when:
    role: user
    content_starts_with_regex: "^\\s*(always|never|toujours|jamais|...)\\b"
  ...
after:
  id: R-HEURISTIC-ALWAYS-NEVER
  when:
    role: user
    content_starts_with_regex: "^\\s*(always|never|toujours|jamais|...|il faut)\\b"
  ...
apply_instructions: |
  Review `before` vs `after`. If accepted, replace the rule with the
  matching `id` in harness/rules.yaml with the `after` version, then
  remove `known_gap: true` from the gap fixture's expected.yaml.
```

## Applying a proposal

1. Read the file end-to-end. The `before`/`after` is the actual diff.
2. The `metric_delta` is the harness's verdict — `regressions: []` means no
   existing fixture broke, `fixtures_fixed` lists which gap fixtures the
   change closes.
3. If you're going to generalize the candidate by hand (e.g. drop the
   over-specific tail of an alternation), do so before pasting.
4. Replace the matching `id:` block in `../rules.yaml`.
5. Remove `known_gap: true` (and `target_rule:`) from the corresponding
   `evals/expected/<name>.expected.yaml` so the regression evals start
   enforcing the closure.
6. Run `python3 scripts/run_evals.py` and `python3 scripts/run_evals.py
   --verify-contracts`. Both must stay green.
7. Commit. Delete or archive the proposal file.

## Why this directory is gitignored

Proposals are per-user, transient artifacts. The repo ships the spec
(`rules.yaml`), the contracts (`evals/expected/*.yaml`), and the proposer
that generates these — not the generated outputs themselves.
